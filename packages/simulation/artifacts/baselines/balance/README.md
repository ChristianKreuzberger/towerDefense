# Deterministic Balance Baselines

This folder stores reproducible baseline artifacts for simulation-balance tuning.

## Scenario Set

The current baseline set is generated by:

- `solo_seed-777_wave2`
- `duo_seed-19_wave2`
- `trio_seed-2024_wave3`

The source of truth for scenario definitions is `packages/simulation/src/baseline-report.cli.ts`.

## Artifact Layout

- `inputs/*.snapshots.json`: deterministic exported `balanceAnalysisExports` envelopes from simulation runs
- `reports/*.report.txt`: deterministic rendered reports generated from the paired input snapshots

## Deterministic Capture Commands

From repository root:

```bash
npm run build
npm run baseline:balance:capture
npm run baseline:balance:report
```

Or from simulation workspace:

```bash
npm --workspace @tower-defense/simulation run report:baseline:capture
npm --workspace @tower-defense/simulation run report:baseline:capture -- --stdout
```

Use these commands when intentionally refreshing the baseline artifacts.

## Drift Check Utility

From repository root:

```bash
npm run baseline:balance:diff:stdout
```

For CI failure on drift:

```bash
npm run baseline:balance:diff:ci
```

CI entrypoint command:

```bash
npm run baseline:balance:verify:ci
```

This runs build + deterministic drift check in non-interactive mode.

Behavior:
- Emits deterministic human-readable summary to stdout with scenario ordering by `scenarioId`.
- Writes machine-readable JSON to `artifacts/baselines/balance/baseline-diff.result.json`.
- Exit code `0`: no drift.
- Exit code `2`: drift detected and `--fail-on-drift true`.
- Exit code `1`: invalid CLI args or artifact read/parse errors.

Drift categories:
- `metric`: structured metric mismatch in derived per-wave/cumulative/player summaries.
- `report`: report text mismatch when both baseline and candidate report files exist.
- `scenario`: scenario missing or extra between compared directories.

## Refresh Guardrails

Use explicit opt-in when intentionally refreshing baseline artifacts:

```bash
BASELINE_REFRESH_CONFIRM=true npm run baseline:balance:refresh:guard
```

Guard behavior:
- Fails if baseline `inputs/` or `reports/` directories are already dirty.
- Runs deterministic capture and then CI-grade drift verification.
- Fails if capture produced no artifact changes.

## PR Author Checklist for Drift

- Confirm drift locally with `npm run baseline:balance:verify:ci`.
- Classify drift as expected vs suspicious.
- Expected drift: document affected scenario IDs and key `kind/path` entries in PR notes.
- Suspicious drift: investigate and resolve cause before baseline artifact refresh/merge.
